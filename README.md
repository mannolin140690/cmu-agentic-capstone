# Agentic Analytics Support Assistant

Capstone Project — Carnegie Mellon University, Agentic AI Program

## Overview

This project explores an AI agent designed to assist users with technical support and documentation research for analytics platforms, including Cloudera, Pentaho, Pyramid Analytics, and Tableau.

The agent will use a ReAct-based reasoning loop, short-term memory, and external retrieval tools to provide evidence-grounded responses while considering software version compatibility.

## Proposed Architecture

- **Frontend:** Streamlit
- **Agent:** Python, LangChain, and LangGraph
- **API:** FastAPI
- **Retrieval:** Retrieval-Augmented Generation (RAG)
- **Vector Database:** Qdrant
- **Infrastructure:** Docker Compose
- **Memory:** Short-term conversational memory

## Current Status

Initial development environment configured. Qdrant is running locally using Docker.

## Data Policy

Only publicly available, synthetic, or anonymized information will be used. No proprietary, confidential, private, or sensitive organizational information will be included.
